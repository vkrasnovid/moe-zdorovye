Мобильное приложение на Flutter для хранения и управления личными медицинскими данными. Все данные хранятся локально на устройстве — без облака, без регистрации.

## Как запустить

### Требования

- Flutter SDK >= 3.x
- Android SDK (min API 21 / Android 5.0)
- Подключённое Android-устройство или эмулятор

### Запуск в режиме разработки

```bash
git clone <repo-url>
cd moe-zdorovye
flutter pub get
flutter run
```

## Как собрать APK

```bash
flutter build apk --release
```

Готовый файл будет находиться по пути:
```
build/app/outputs/flutter-apk/app-release.apk
```

Для сборки с разделением по ABI (меньший размер):
```bash
flutter build apk --split-per-abi
```

## Функции приложения

### Главный экран

- Дашборд с карточками всех категорий и счётчиком записей в каждой
- Список последних 5 записей
- Кнопка быстрого добавления (FAB)

### 1. Анализы крови / мочи

Хранение результатов лабораторных исследований: название, дата, лаборатория, прикреплённые файлы (фото, PDF), заметки.

### 2. Медицинские снимки

Рентген, КТ, МРТ, УЗИ: тип исследования, область тела, дата, клиника, прикреплённые изображения и файлы.

### 3. Рецепты и назначения

Данные о назначениях врача: имя и специальность врача, дата, список препаратов или свободный текст, прикреплённые документы.

### 4. Вакцинации

Журнал прививок: название вакцины, дата, номер дозы, клиника / врач, дата следующей дозы.

### 5. Хронические заболевания и аллергии

Постоянный справочник состояний: название, дата постановки диагноза, степень тяжести, заметки.

### 6. Показатели здоровья

Ручной ввод измерений с графиками истории:

| Показатель | Единица |
|---|---|
| Артериальное давление | мм рт.ст. |
| Вес | кг |
| Температура тела | °C |
| Сахар крови | ммоль/л |
| Пульс | уд/мин |

### QR-шеринг (режим врача)

Позволяет быстро поделиться выбранными записями с врачом без передачи устройства:

1. Пользователь выбирает нужные записи и нажимает «Поделиться».
2. Приложение запускает временный HTTP-сервер на порту `8080` и генерирует QR-код с URL вида `http://<IP>:8080`.
3. Врач сканирует QR-код и открывает страницу в браузере — отображаются выбранные записи с вложениями (только для чтения).
4. При закрытии экрана шеринга сервер автоматически останавливается.

> Оба устройства должны быть подключены к одной Wi-Fi-сети.

### Управление записями

- Полный CRUD для всех категорий
- Прикрепление нескольких файлов (фото с камеры / галереи, PDF)
- Встроенный просмотрщик изображений (zoom) и PDF
- Поиск по всем записям
- Фильтрация по категории
- Сортировка по дате
